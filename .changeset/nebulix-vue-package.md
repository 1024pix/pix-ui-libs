Create `@1024pix/nebulix-vue`, the Vue 3 implementation of the Pix Design-System, starting with `PixButton` and `PixIcon`.

It ships the same Sass as `@1024pix/nebulix-ember` (`@use 'nebulix-styles'`), and a `nebulix()` Vite plugin that sets up its `loadPaths` and serves the fonts and the icon sprite under `/@1024pix/nebulix-vue/…`.
