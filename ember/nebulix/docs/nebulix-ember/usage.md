# Utiliser un composant

Pour utiliser un composant, ajoutez-le à votre template Ember comme n'importe quel autre composant.

```gjs preview
import { PixButton } from '@1024pix/nebulix-ember';

<template>
  <PixButton>
    Enregistrer
  </PixButton>
</template>
```
